SAND-64 : 12 段差分特性で確率 p = 2^-58 をもつものの全数列挙
======================================================================

[1] 最適性
  重み <= 57 の 12 段特性は存在しない (SAT モデルは UNSATISFIABLE, 55s)。
  重み <= 58 は SATISFIABLE。したがって 12 段の最小重みはちょうど 58 であり,
  以下の特性はすべて最適特性である。

[2] 総数
  重み 58 の 12 段差分特性                 : 12288 本
  相異なる入力差分 (dX^0, dY^0)            : 352
  相異なる出力差分 (dX^12, dY^12)          : 352
  相異なる (入力, 出力) 対                 : 6144
  各 (入力, 出力) 対はちょうど 2 本の特性をもつ
   => その差分の確率は少なくとも 2 * 2^-58 = 2^-57
  1 つの入力差分に対応する出力差分: 12 個 … 入力差分 256 個
  1 つの入力差分に対応する出力差分: 32 個 … 入力差分 96 個

[3] ラウンド重みベクトル (w_1,...,w_12) の内訳
  実現可能な重みベクトルは 4 通りしかなく, 2 通りの時間反転対をなす。
    [4, 2, 0, 2, 4, 9, 9, 8, 6, 4, 6, 4]  : 5376 本
    [4, 6, 4, 6, 8, 9, 9, 4, 2, 0, 2, 4]  : 5376 本
    [2, 7, 4, 7, 8, 9, 9, 4, 2, 0, 2, 4]  : 768 本
    [4, 2, 0, 2, 4, 9, 9, 8, 7, 4, 7, 2]  : 768 本

[4] 検証
  (a) SSb の同時 DDT の CNF は 2^15 通りを全探索して厳密性を確認済み。
  (b) 全 12288 本について, SAT とは独立な転送行列計算で各ラウンド遷移の
      厳密な 32bit 遷移数を数え直した。不可能な遷移は 0 本,
      各特性のラウンド内クラスタリングを含む厳密重みも全て 58 で一致した。
  (c) 完全性: 12288 本すべてをブロッキング節として与えた「重みちょうど 58」の
      SAT モデルは UNSATISFIABLE (125s)。すなわちこれ以外に重み 58 の
      12 段特性は存在しない。分割方法に依存しない証明である。
